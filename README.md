麻雀轻跳 (Sparrow Skip)

一款开源的 Android 广告自动跳过工具。基于无障碍服务，通用引擎开箱即用，顽固广告可用悬浮窗录制规则。数据全部存本机，不联网。

![Android](https://img.shields.io/badge/Android-7.0%2B-green)

✨ 特性

🚀 通用引擎 · 开箱即用

无需任何配置，自动识别开屏广告的「跳过」类按钮。

· 首尾白名单匹配：只认核心词 跳过 / 跳過 / 略過 / skip / skipad，拒绝「跳过片头」「跳过联网」等误判
· 动态数字识别：支持 跳过5s、5秒跳过、Skip5s 等写法
· 多重防误点：搜索框 / 列表容器 / 输入法区域 / CTA 按钮 / 页面排除词全部拦截
· 可见性校验：只点真正显示在屏幕上的节点
· 智能去重：同应用同文本 10 分钟只点一次，同位置 3 秒只点一次
· 前台校验：后台应用的事件直接跳过，不在后台乱点
· 严格模式：首屏文本数超阈值判定为内容页，不执行（可调 5~500，默认 30）
· 点击前稳定检查：页面滚动或手指在屏 350ms 内不点，越界不点

🎯 脚本引擎 · 录制顽固广告

针对通用引擎处理不了的广告，用悬浮窗录制规则。三种点击方式，录制时按填法自动判定：

模式 填法 适用场景
固定坐标 准心拖到按钮上记录坐标 按钮位置固定的广告
点控件 填目标控件序号 按钮会换位置、换分辨率
动态坐标 勾选动态坐标 + 选锚点角 关闭按钮跟着广告图移动/缩放

· 条件录制：检视控件拾取多个控件 ID 作为前置条件
· 续点：支持「跳过 → 关闭 → 确认」多步点击，每个续点独立延迟（100~10000ms）
· 冷却时间：每条规则独立设置
· 生效范围：首屏 / 应用内弹窗
· 规则管理：更新坐标、单条启停、长按应用批量开关/删除

🛡️ 白名单 · 防误触

· 首次启动自动加入系统应用和桌面
· 分类管理：资金 / 游戏 / 其他 / 系统，支持分类全选
· 白名单内应用完全不做任何自动点击
· 自身应用与桌面启动器强制保护

🎈 悬浮窗

· 自由拖动，点左上角「轻跳」收起成小圆点
· 小圆点自动吸附左右边框，点击展开居中
· 检视 / 准心显示时不收起，录制不被打断
· 录制流程统一：主页或单应用入口均可录制，确认后自动跳转配置页

📦 更多

· 备份恢复：规则导出/导入剪贴板，合并策略不覆盖现有数据
· 深浅色主题：跟随选择记住
· 跳过统计：今日 / 累计 / 规则数，长按清空
· 常驻通知：显示运行状态，可选关闭；「录制模式」自动切换
· 去除后台卡片：可选不在最近任务显示
· 延迟控制：单应用延迟 / 全局延迟

🔧 安装

要求

· Android 7.0 (API 24) 及以上
· 无需 Root

步骤

1. 下载最新 Release 中的 SparrowSkip-x.x.x.apk
2. 允许「安装未知来源应用」后安装
3. 打开 App → 点「去开启」→ 在系统设置中开启无障碍服务
4. 回到 App → 点「去授权」开启悬浮窗权限
5. 通用引擎默认开启，开屏广告会自动点击「跳过」

⚠️ 部分国产 ROM 需要额外允许「后台弹出界面」「自启动」权限，否则无障碍服务可能被系统杀掉。

🎬 录制顽固广告

主页录制（推荐）

```
打开悬浮球 → 切到目标应用广告页
→ ① 检视控件（框出条件控件）
→ ② 准心坐标（拖到跳过按钮）
→ 保存规则 → 输入条件序号
→ 自动跳转配置页 → 保存
```

单应用录制

```
应用规则页 → 新建规则 → 自动跳到目标应用并启动悬浮球
→ 录制 → 确认 → 跳编辑页 → 保存
```

三种点击方式怎么填

· 目标控件序号填了 → 点控件模式（按 ID 点控件中心，不怕换位置）
· 目标控件序号空着 + 勾了动态坐标 → 动态坐标模式（锚点 + 偏移）
· 两者都没有 → 固定坐标模式（点准心记录的位置）

🏗️ 技术架构

```
AccessibilityService 监听事件
        │
        ▼
   后台单线程队列（避免阻塞主线程）
        │
        ▼
   白名单校验 → 严格模式 → 脚本规则 → 通用引擎兜底
        │
        ▼
   dispatchGesture 模拟点击
```

· 语言：Kotlin
· UI：原生 View / RecyclerView
· 存储：SharedPreferences + 本地 JSON
· 网络：无（完全离线）

❓ 常见问题

Q：无障碍服务老是自动关闭？
A：国产 ROM 请在系统设置中允许「自启动」「后台运行」，并将省电策略设为「无限制」。

Q：点击了但广告没关掉？
A：部分广告的跳过按钮是自绘 View，通用引擎会尝试在广告容器内找空按钮。仍不行请用悬浮窗录制脚本规则。

Q：规则录了不生效？
A：先确认应用不在白名单里；再检查生效范围是否匹配（首屏 / 应用内）；脚本规则只受自身冷却约束。

Q：坐标偏了？
A：悬浮面板勾选「补齐状态栏」再试；旧规则需点「更新坐标」重取。

Q：数据会上传吗？
A：不会。所有规则、坐标、白名单全部存本机，App 无网络权限。
